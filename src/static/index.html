Create Pull Request / Merge Request

For a fork, set the Base repository to the upstream (e.g. opentelekomcloud-docs/test-repo) to open a PR against the original project. The app posts to that repo with head = forkowner:your-branch and base = base-branch. Same-repo PRs post to your own repo with plain branch names.

Import documentation

Convert a .docx, .html or .md file to reStructuredText. Embedded images are saved to _static/images/. Files are written into the chosen documentation folder and staged — review them in the editor before committing.

Add a picture

The image is saved next to the current file, in <dir>/_static/images/, and an .. image:: (or .. figure::) directive is inserted at the cursor / selection. It shows in the live preview.
